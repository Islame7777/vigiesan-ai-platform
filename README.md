# 🏥 VigieSan

VigieSan is an AI-powered healthcare platform designed to assist healthcare professionals through intelligent medical document analysis, multimodal retrieval, and evidence-based information access.

## 🚀 Current Features

- Medical Document Processing
- Multimodal RAG
- Vector Search with Qdrant
- Intelligent Knowledge Retrieval
- Prompt Engineering Workflows
- Streamlit User Interface
- Dockerized Environment
